## Local development

```bash
cd twiga-harvest
npm install
npm run dev
```

Build:

```bash
npm run build
```

## Deploy on Vercel

- Live: https://twiga-harvest.vercel.app  
- GitHub: https://github.com/Mr-Robbin/twiga-harvest  

This repo is connected to Vercel. Pushes to `main` auto-deploy to production.

`vercel.json` already rewrites all routes to `index.html`, so direct links like `/about` and `/contact` work.

To attach the custom domain later: add `twigaharvest.co.tz` in the Vercel project Domains settings.
