## Local development

```bash
cd twiga-harvest
npm install
npm run dev
```

Build:

```bash
npm run build
```

## Deploy on Vercel

1. Import the `twiga-harvest` folder (or repo) into Vercel.
2. Framework preset: **Vite**
3. Build command: `npm run build`
4. Output directory: `dist`
5. Add domain: `twigaharvest.co.tz` (and `www` if needed)

`vercel.json` already rewrites all routes to `index.html`, so direct links like `/about` and `/contact` work.
